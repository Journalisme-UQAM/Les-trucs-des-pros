# 📣 Porte-paroles gouv.

## Gouvernement fédéral

Vous trouverez les coordonnées des porte-paroles des agences et ministères du gouvernement fédéral sur la page [**Coordonnées pour les médias**](https://www.canada.ca/fr/nouvelles/coordonnees-medias.html)**.**

## Gouvernement du Québec

L'équivalent québécois est accessible sur la page [**Coordonnées des responsables des relations avec les médias**](https://www.quebec.ca/nouvelles/responsables-medias). Mais cette liste est pour les porte-paroles des ministères, le volet administratif de l'État.

Pour le volet politique, si vous cherchez à joindre le porte-parole d'une ministre, la Bibliothèque de l'Assemblée nationale met régulièrement à jour une [**liste du personnel politique des cabinets ministériels**](https://www.bibliotheque.assnat.qc.ca/DepotNumerique_v2/AffichageNotice.aspx?idn=714). Toutes les versions depuis 2009 sont accessibles.
