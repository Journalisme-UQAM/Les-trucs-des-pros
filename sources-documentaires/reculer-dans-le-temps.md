# 🦕 Reculer dans le temps

## Wayback Machine

<figure><img src="https://miro.medium.com/v2/resize:fit:1400/1*KIQIf2nuaR4BClq7OjL8mQ.png" alt="" height="254" width="700"><figcaption></figcaption></figure>

La [**Wayback Machine**](https://web.archive.org/) permet de voir l’apparence qu’avait un site web à une époque donnée et, ainsi, de retrouver des informations qui ont été effacées du web. Fascinant, comme dirait Charles Tisseyre.

### Archive Today

Si vous ne trouvez rien dans la Wayback, [**Archive Today**](https://archive.ph/) est une solution de rechange qui fait cependant un archivage moins exhaustif du web.

### Common Crawl

L'écumage le plus exhaustif du web est réalisé par [**Common Crawl**](https://commoncrawl.org/). Mais le désavantage, c'est que ce site contient des quantités phénoménales de données difficiles à extraire.

## Documents numérisés

L'organisation qui héberge la Wayback Machine, [**Archive.org**](https://archive.org/), continent également une masse incroyable de documents numérisés. Leur collection de livres publiés au Québec, par exemple, est étonnante!
